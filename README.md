#  Arduino Dino Game

This is a mini LCD-based Dino Game built using an Arduino UNO and push buttons. It simulates the classic Chrome Dino run game with simple obstacle dodging.

##  Technologies Used
- Arduino UNO
- LCD Display
- C/C++ (Arduino IDE)
- Push Buttons

## Files Included
- `dinogame_code.ino`: Main Arduino sketch
- `project_report.pdf`: Project report (cleaned version)
